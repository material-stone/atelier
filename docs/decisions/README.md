# 결정 기록

기능을 추가하거나 고칠 때마다 누가 어떤 판단을 했고 왜 그랬는지 남깁니다. 판단한 사람별로 파일을 나눴습니다.

- [user-decisions.md](user-decisions.md) — 사용자(프로젝트 주인)가 정한 것: 방향, 요구사항, 승인·거절
- [claude-decisions.md](claude-decisions.md) — Claude가 구현하면서 정한 것: 설계, 대안 비교, 기본값

## 쓰는 법

- 새 항목은 각 파일의 맨 위에 추가합니다. 최신이 위에 옵니다.
- 같은 작업의 항목은 두 파일에서 같은 제목(`## 날짜 · 기능 이름`)을 써서 서로 찾기 쉽게 합니다.
- 항목마다 **결정**, **이유**를 적고, 버린 대안이 있으면 **대안**에 적습니다.
- 나중에 결정이 바뀌면 옛 항목을 지우지 않고 새 항목에서 "○○ 결정을 바꿈"이라고 적습니다.
